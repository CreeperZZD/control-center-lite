# 控制中心（CCLite）

七彩虹隐星 G16 2024（RTX 4070，广达模具，同模具：神舟 T8 Pro 等）的轻量 Windows 控制面板。
基于对原版 Control Center 的 **WMI-EC 协议逆向**实现，**可与原版共存**，配置互相打通。

![screenshot](docs/screenshot.png)

## 功能

| 页面 | 功能 |
|---|---|
| 概览 | 办公/游戏/狂暴模式切换（电源计划联动 + **灯效/亮度联动**）、CPU/GPU 温度与风扇转速、内存/多磁盘、**屏幕亮度、系统音量/静音**、本机配置 |
| 灯光 | 键盘 A/B/C 三区颜色、**每个灯效档案独立启用开关**、圆形色轮调色盘、常亮/呼吸/多彩循环/流光溢彩、亮度三档（NLY 三档）、按分区点击直接调色 |
| 风扇 | CPU/GPU 温度-转速曲线（8 档），3 组预设，恢复自动 |
| 系统 | 显示输出切换（混合/独显直连/集显）、Win 键锁定、开机自启、诊断信息 |
| 托盘 | 左键打开面板；右键：系统模式、键盘亮度三档、灯效开关、Win 键锁定、开机自启、退出 |

**亮点**：切系统模式时自动恢复该模式的键盘灯效档案与屏幕亮度（原版缺失的联动）；每个灯效档案独立启用开关（关=该档案不点亮，但配置照常编辑保存）；**自定义接管**（开启后无论切到哪个系统模式都保持自定义灯效）。

## 安装（同款电脑，3 步）

1. 从 [Releases](../../releases) 下载 `控制中心-CCLite-便携版.zip`，**解压到任意目录**
2. 双击 `CCLite.exe`，弹出管理员授权点"是"（写 EC 与注册表需要）
3. 完成 —— 程序常驻右下角托盘（蓝色闪电），关闭窗口即最小化到托盘

> 自包含单文件，**无需安装 .NET 运行时**。
> 无需安装原版 Control Center（BIOS 自带 WMI 接口）；若个别机器接口异常，装一次原版即可。

### 开机自启

面板内 → 系统 → 打开「开机自启」（任务计划最高权限，`--tray` 参数静默启动，不弹窗口）。

### 卸载

关闭开机自启后删除程序目录；如需彻底清理，删除任务计划 `CCLitePanel` 与
`HKLM\SOFTWARE\WOW6432Node\NL5\ControlCenter` 下 `LedOn_* / BrightnessMode* / Unified*` 等新增值。

## 从源码构建

```
# 需要 Windows 10/11 x64 + .NET 9 SDK
git clone https://github.com/CreeperZZD/control-center-lite.git
cd control-center-lite/cc-lite
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:EnableCompressionInSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o publish
publish\CCLite.exe
```

## 使用要点

- **灯效档案**：办公/游戏/狂暴/自定义四套独立配色，"跟随当前模式"随系统模式自动切换
- **选中模式灯效开关**（档案标题行右侧）：每个档案独立启停；关=切到该档案时键盘熄灭，但下方配置照常编辑保存
- **键盘预览**：点击 A/B/C 分区任意位置 → 自动切常亮防闪烁 → 弹出色轮调色盘（点外部/×/Esc 收起）
- **亮度三档**：熄灭/50%/100%（本机 EC 仅认 0/1/2 三档，熄灭档仍保留约 5% 底亮，为硬件特性）
- **三分区统一颜色**：开启后一键整体调色，关闭恢复各区独立配色
- **按系统模式记忆亮度**：切模式自动恢复该模式保存的屏幕亮度

## 逆向原理（摘要）

通信链路：`控制面板 → WMI root\wmi\RW_GMWMI（32 字节缓冲区）→ BIOS ACPI → EC`

| 命令码 (a1) | 功能 |
|---|---|
| 0x0100 | LED：a2=槽位（3/4/5=键盘三区），a3=`[模式4b][亮度4b][R][G][B]` |
| 0x0200 | 读 CPU/GPU 温度与转速；写 Win 键锁定 |
| 0x0203 | 显示输出（1 混合 / 2 独显 / 3 集显） |
| 0x0205/0x0206 | 风扇转速百分比 / 自定义风扇开关 |
| 0x0300 | 系统模式（0 狂暴 / 1 游戏 / 2 办公） |

`a0 = 0xFA00 读 / 0xFB00 写`。完整协议与数据格式见 [cc-lite/docs/逆向笔记.md](cc-lite/docs/逆向笔记.md)。

**硬件限制**（实测）：EC 单次写入 ≈ 24ms（三区一帧 72ms → 上限 10–14 FPS），且只有 A/B/C
三个分区可寻址——因此**逐键自定义灯效硬件不支持**；固件自带灯效跑在 EC 里，最流畅。
