# 轻控面板 (CCLite)

七彩虹隐星 G16 2024（RTX 4070，广达模具，同模具：神舟 T8 Pro 等）的轻量控制面板。
基于对原版 Control Center v3.0.0.17 的逆向分析实现，**可与原版共存**，配置互通。

![预览](../docs/screenshot-placeholder.png)

## 功能

| 页面 | 功能 |
|---|---|
| 概览 | 办公/游戏/狂暴模式切换（含电源计划联动 + **灯效联动**）、CPU/GPU 温度、双风扇转速、内存占用（含 DDR5-4800 频率）、所有接入磁盘分盘显示、本机配置信息 |
| 灯光 | **键盘灯效预览图**（三区实时上色）、键盘 A/B/C 三区独立颜色、**三分区统一颜色开关**（开启屏蔽分区分设并记忆原设置，关闭恢复）、调色盘（常用色 / 色相 / 饱和度 / RGB / 十六进制输入）、灯效模式（关闭/常亮/呼吸/多彩循环/流光溢彩，选中即实时上键盘）、**亮度三档 熄灭/50%/100%（NLY 机型 EC 仅认 0/1/2）**、总开关；灯效按模式存 4 套档案；**离开灯光页自动回到"跟随当前模式"** |
| 风扇 | CPU/GPU 温度-转速曲线（8 档固定温度点）、3 组预设、恢复自动（本机无第三风扇，SYS 恒自动） |
| 系统 | 显示输出切换（混合/独显直连/集显，需重启，流程同原版）、Win 键锁定、开机自启（任务计划程序最高权限）、诊断信息 |
| 托盘 | 右键菜单：系统模式切换、键盘亮度三档、灯光总开关、Win 键锁定、开机自启；双击打开面板 |
| 动效/体验 | 导航蓝色指示条滑动动画、页面切换淡入位移过渡、细样式滚动条（贴合右边缘，悬停变宽）、最小化/托盘后自动降频轮询 + 修剪内存占用 |

## 修复的原版 Bug

**在原版灯光页给每种模式设置好灯效后，回模式页切换模式，灯效不变。**
原因：原版切模式链路（UI 点击 / Fn 热键）只发 `0x0300` 给 EC 并切 Windows 电源计划，
从不重放对应灯效档案（`LEDModuleControl` 只在进入灯光页或点击灯效模块按钮时触发）。

本面板的修复：
1. 面板内切模式 → 自动重放该模式档案（办公→PowerSaving / 游戏→Game / 狂暴→HighPerformance）；
2. 托盘常驻时监视注册表 `ModeBeforeDC` —— 用原版 CC 或 Fn 热键切模式也会自动联动灯效。

## 构建 / 运行

```
dotnet publish -c Release -r win-x64 --self-contained false -o publish
publish\CCLite.exe     # 需管理员权限（WMI 写 + HKLM 注册表）
```

要求：Windows 10/11 x64 + .NET 9 Desktop Runtime；机器需存在 `root\wmi\RW_GMWMI` 接口
（广达模具机型随原版 Control Center 安装启用，面板启动时会自检）。

## 与原版共存说明

- WMI `RW_GMWMI` 每次调用无状态，写相同数据幂等，两边互不破坏
- 灯效档案共用 `HKLM\SOFTWARE\WOW6432Node\NL5\ControlCenter` 的
  `Game / HighPerformance / PowerSaving / Custom`，任一方修改双方立即可见
- Fn 热键、EC 事件（GMC_WMIEvent）仍归原版 Daemon 处理，本面板不参与
- 自定义风扇：两边读取同一份曲线数据；本面板退出时自动恢复 EC 自动调速
- 注意：用本面板切模式时，原版 CC 窗口上的模式单选不会自动刷新（纯 UI 显示问题，不影响状态）

## 已知不支持的功能

- **电池充电阈值（如 80% 停充）**：本机 `root\wmi` 仅暴露 Windows 标准电池状态类，
  无任何 OEM 充电阈值接口；原版 CC 的 ACPI 命令表里也没有电池相关命令。
  该功能需要 BIOS/EC 固件支持（联想/华硕等是各自在 BIOS 里实现的私有接口），无法软件模拟。

## 独立使用 / 共存

- WMI-ACPI 接口（`ACPI\PNP0C14`）由 BIOS + Windows 系统驱动提供，**不依赖原版 Control Center 进程运行**
  ——原版不开也能单独使用；两边同时开也互不冲突
- 桌面快捷方式「轻控面板.lnk」指向 `publish\CCLite.exe`；开机自启走任务计划程序（CCLitePanel）

## 项目结构

```
cc-lite/
  Services/   GmWmiService   RW_GMWMI 32字节读写（0xFA00读/0xFB00写，子命令见逆向笔记）
              GMReg          共用注册表读写
              LedService     键盘三区灯效（slot 5/4/3，数据[mode4b][亮度4b][R][G][B]）
              PowerModeService 模式切换 + 电源计划 + 灯效联动
              FanService     曲线计算/下发（5s 定时器）
              DisplayService 显示模式/Win键
              MonitorService 2s 轮询监控 + 外部模式变化观察
  Views/      MainWindow + Overview/Lighting/Fan/System 四页
  ProtoTest/  只读协议冒烟测试（验证 EC 通信，不改变任何状态）
```

协议细节见 `docs/逆向笔记.md`。

## 运行形态（v1.1 更新）

- **开机自启**：系统页打开开关后写入任务计划 `CCLitePanel`，命令带 `--tray`，开机只驻留托盘、不弹窗口
- **托盘**：左键单击 / 双击打开主界面；右键菜单含系统模式、键盘亮度三档、灯光总开关、Win 键锁定、开机自启、固定到任务栏、退出
- **关闭按钮 (X)**：缩到托盘，不退出；退出走托盘菜单
- **按需刷新**：窗口隐藏/最小化时**完全停止硬件轮询**（实测后台 CPU 占用 0），仅每 8 秒比较一次注册表保证"外部切模式→灯效联动"仍生效；窗口打开即恢复 1 秒实时刷新
- **托盘图标常驻**：自动写入 `HKCU:\Control Panel\NotifyIconSettings` 的 `IsPromoted=1`，图标即桌面同款蓝色闪电

## 键效分区（按实机确认，v1.2）

| 区 | 范围 |
|---|---|
| A | 到 **F5 / 4 / R / F / C / 左 Alt** 为止（含左 Ctrl/Fn/Win/Alt） |
| B | 到 **PrtSc / = / ] / 单引号 / 斜杠 / 右 Ctrl** 为止 |
| C | B 右侧的全部：Delete、Home、End、PgUp、PgDn、Backspace、反斜杠、主 Enter、右 Shift、整个数字小键盘（含 + / - / Enter / 0 / .）、方向键 |

灯光页点击键盘预览**任意位置**即按就近键判定分区，并自动把该区切为常亮（防止呼吸/流光闪烁影响调色）后打开色轮调色盘。

## 显示与声音（v1.4）

概览页新增「显示与声音」卡片：

- **屏幕亮度**：`root\wmi WmiMonitorBrightnessMethods`（内建屏有效；外接屏需 DDC/CI，不支持）
- **系统音量 / 静音**：CoreAudio `IAudioEndpointVolume`，控制默认播放设备

同时调色盘恢复为**弹窗形态**（你更习惯的方式）：`StaysOpen=False` 由系统负责“点外部收起”，
并把打开动作延迟到本次点击的鼠标事件结束之后（`DispatcherPriority.Input`），
因此不会再出现“弹出即消失/一拖动就消失”。

## 灯效现状

仅使用固件自带灯效（常亮/呼吸/多彩循环/流光溢彩）。软件自定义动效因 EC 单次写入约 24 ms
（三区一帧 ≈72ms → 10~14 FPS）会出现肉眼可见闪烁，已移除。
本机 EC 无逐键寻址接口，**逐键自定义灯效硬件不支持**。

## 按系统模式记忆屏幕亮度（v1.5）

与原版一致：切换系统模式（办公/游戏/狂暴）时自动恢复该模式记忆的屏幕亮度。

- 记忆值存于 `BrightnessMode0/1/2`（0=狂暴 1=游戏 2=办公）
- 拖概览页亮度滑条即写入当前模式的记忆
- 面板内切模式、原版/Fn 热键切模式（注册表监视）都会触发恢复
- 某模式第一次切换时以当时亮度作为基线，之后拖动滑条更新

## 调色盘弹窗（v1.5 修复）

`StaysOpen=False` 弹窗会在"打开它的那次点击"的 MouseUp 时被判定为点外部而立即关闭。
已改为 **250ms 定时器延迟打开**（等 Down→Up 序列彻底结束后再开），点击分区→约 0.25s 后弹窗稳定出现，
内部拖动色轮不消失；点外部 / × / Esc 收起。静音开关旁已加"静音"文字标签。
