# 广达模具 Control Center 逆向笔记

对象：七彩虹隐星 G16 2024（RTX 4070）随机的 Control Center v3.0.0.17 "Standard"（NL5 版）。
同模具机型（神舟 T8 Pro 等）理论上同协议。反编译产物：.NET 主程序已用 ilspycmd 还原为 C#。

## 1. 通信链路

```
ControlCenter.exe (WPF/.NET)
   │ ManagementObject.Put() 写 32 字节 → 触发 BIOS ACPI SMI → EC
   ▼
WMI root\wmi → RW_GMWMI（实例 ACPI\PNP0C14\0x1_0，属性 BufferBytes[32]）
```

- `ControlCenter.sys/64.sys` 内核驱动是遗留物，主程序未使用
- 事件通道：`GMC_WMIEvent`（Fn 热键/插拔适配器/相机键等），由主程序与 Daemon 订阅
- 32 字节布局（小端）：`a0:u16 | a1:u16 | a2..a6:u32×5 | rev0:u32 | rev1:u32`
- **a0 = 0xFA00 读 / 0xFB00 写**；a1 = 子命令码；a2~a6 参数/返回
- 全部命令：写 BufferBytes → Put → 重新查询读回

## 2. 命令表（a1 子命令码）

| a1 | 读(0xFA00) | 写(0xFB00) |
|---|---|---|
| 0x0100 | LED 状态（a2=RGB） | LED：a2=槽位，a3=32位灯效数据 |
| 0x0200 | a2=CPU温度 a3=GPU温度 a4=CPU转速 a5=GPU转速（低16位） | Win键锁定：a6=1锁定/0解锁 |
| 0x0201 | a2=机型 SKUID（48=非RGB键盘） | — |
| 0x0202 | a4=HSR支持 a5=相机 a6=DDS支持（==2 才算支持） | — |
| 0x0203 | a2=当前显示模式 a3=HDMI状态 | 显示模式：a2=1混合/2独显直连/3集显（重启生效） |
| 0x0204 | HSR 状态 | 设 HSR |
| 0x0205 | 默认风扇表 | 风扇转速%：a2=CPU a3=GPU a4=SYS（0xFF=自动） |
| 0x0206 | a2=自定义风扇开关 a4=适配器状态 | 自定义风扇开关：a2=0/1 |
| 0x0207 | a2=SYS温度 a3=SYS转速 | — |
| 0x0300 | — | 系统模式：a2=0狂暴/1游戏/2办公 |
| 0x0400 | EC 事件读取 | 事件确认：EventID 2/3/4 → a2/a3/a4=1 |

## 3. LED 灯效数据（32 位）

```
[bit31-28 灯效模式][bit27-24 亮度0-15][bit23-16 R][bit15-8 G][bit7-0 B]
模式：0=关闭 1=常亮 3=呼吸 6=多彩循环 7=流光溢彩(仅键盘)
槽位：3=键盘C区 4=键盘B区 5=键盘A区 6=键盘全部 7=尾部灯条 8=Logo灯 0=全部
```

灯效档案注册表（`HKLM\SOFTWARE\WOW6432Node\NL5\ControlCenter`）：

| 值名 | 含义 |
|---|---|
| `Game`(模块0) / `HighPerformance`(1) / `PowerSaving`(2) / `Custom`(3) | 5 段分号分隔十六进制：`logo;trunk;LED1(A区);LED2(B区);LED3(C区)`，每段=32位灯效数据 |
| `LEDModule` | 当前激活灯效模块 0-3 |
| `ModeBeforeDC` | 当前系统模式 0狂暴/1游戏/2办公 |
| `LEDWizard` | 灯光总开关；`Alpha`=键盘亮度 |
| `WinKey` | Win键锁定 |
| `FanControlStatus`/`FanControlSelect` | 自定义风扇开关/预设号 |
| `UserFan1..3` | 曲线 `"cpu×8;gpu×8"`（逗号分隔，0-100） |
| `UserFan1..3_SYS` | SYS 曲线（本机无第三风扇，恒 0xFF） |

曲线温度点固定 `{30,40,50,60,70,80,90,100}°C`，取档逻辑：`temp ∈ [T[m], T[m]+10)`。

## 4. 系统模式切换链路（原版）

UI 点击 `power_*_Click` 或 Fn 热键（EC 事件 → WndProc 4401/4402/4403）→
`power_*_click_func` → ① `PowerSetActiveScheme`（狂暴 a9932169-… / 办公 5DA85D85-… / 游戏 653fbb7f-…）
② `SetPowerMode`(0x0300) ③ 写 `ModeBeforeDC`。
**没有第 ④ 步"重放灯效"——这就是原版切模式灯效不变的根因。**
灯效重放 `LEDModuleControl` 只在：进入灯光页 / 点击灯光页底部灯效模块按钮时发生。

## 5. 原版进程分工

| 进程 | 职责 |
|---|---|
| ControlCenter.exe | UI + 监控(5s) + 模式/灯效/风扇写 + WMI 事件订阅 + Fn 模式热键 |
| ControlCenterDaemon.exe | 常驻：Fn 亮度热键、电源状态变化时写 `ModeBeforeDC`/电源计划 |
| CTS.exe / CDSOSrv.exe / ClosePro.exe | 安装/校验/关闭辅助 |

## 6. 本机实测（SKUID=52，隐星G16 24 4070）

- 0x0200：CPU/GPU 温度与双风扇转速实时可读
- 0x0207：SYS 风扇 0 RPM（本机无第三风扇）
- 0x0203：显示模式读回 =2（独显直连）
- 0x0206：自定义风扇状态与注册表一致
- 0x0200 写（WinKey 幂等回写）成功 → 写通路有效
